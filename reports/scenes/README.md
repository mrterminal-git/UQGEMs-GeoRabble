# Scenes

Generated interactive HTML and 3D scene exports are written here. Phase 2 creates a
self-contained PyVista test scene. Phase 9 creates
`uq_pilot_integrated.html`, a self-contained Plotly scene combining real pilot terrain,
mixed-LoD buildings, a LiDAR preview and display-only public utility alignments.

Phase 11 creates `uq_pilot_textured.html`, a self-contained PyVista/vtk.js presentation
scene, and `uq_pilot_skin_viewer.html`, a small local wrapper for switching between the
Phase 9 analysis skin and Phase 11 presentation skin. Keep all three files together.
